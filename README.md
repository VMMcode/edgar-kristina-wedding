# Эдгар и Кристина

Свадебное приглашение, 30 января 2027 года. HTML, CSS, браузерный JS и Vercel Function без внешних зависимостей.

## Google Таблица

1. В таблице проекта оставьте существующую вкладку `Лист1`. ID таблицы уже указан в `apps-script/rsvp.gs`.
2. Удалите ссылку из A1. Вставьте в A1 следующую строку (между названиями — табуляция):

```text
Дата ответа	Имя и фамилия	Присутствие	Сопровождающие взрослые	Будут дети
```

3. Откройте «Расширения → Apps Script», замените весь прежний код содержимым `apps-script/rsvp.gs` и сохраните. Настройка свойств скрипта и запуск `setup` не нужны.
4. «Развернуть → Новое развертывание → Веб-приложение»: выполнять от вашего имени, доступ «Все». Предоставьте разрешения и скопируйте адрес, заканчивающийся на `/exec`.
5. Если развертывание уже есть: «Управление развертываниями → Изменить → Новая версия → Развернуть».
6. `doPost` запускается POST-запросом сайта, а не кнопкой «Выполнить» в редакторе.

Скрипт записывает только ответы в пять колонок A–E. Листы и заголовки не создаёт. Формат столбца A задайте вручную как дату со временем, часовой пояс таблицы — Москва.

## GitHub и Vercel

Публикуйте содержимое этой папки отдельным репозиторием. Макеты, исходная музыка и локальные настройки исключены. В Vercel импортируйте репозиторий, Framework Preset: Other, корень проекта — корень репозитория; без команды сборки и без отдельной папки вывода. Vercel обслуживает статические файлы и `/api/rsvp`.

В Environment Variables Vercel добавьте для Production и Preview:

- `GOOGLE_SCRIPT_URL` — адрес веб-приложения `/exec`. Другие переменные не нужны; ранее добавленный `RSVP_SECRET` больше не используется.

После изменения переменных создайте новый деплой. Ответы Preview тоже попадают в эту таблицу; тестовые ответы явно подписывайте «ТЕСТ».

## Проверка перед сдачей

`npm test` проверяет сервер и Apps Script с подменой сервисов: успешную запись, отказ, валидацию, ошибки Google, ошибки записи и срок. Это не заменяет проверку реальной таблицы.

- На опубликованном сайте открыть конверт, проверить музыку и переключатель звука на телефоне.
- Отправить «ТЕСТ — присутствую» с сопровождающим и детьми; сверить строку в таблице.
- Отправить «ТЕСТ — не приду»; зависимые поля должны быть пустыми в таблице.
- Проверить узкий экран 320 px, обычный телефон и компьютер, отсутствие ошибок консоли и пропавших файлов.
- После деплоя проверить превью ссылки: Open Graph и Twitter Card используют `https://edgar-kristina-wedding.vercel.app/` и обложку `img/social-preview.png`. При смене домена обновить canonical, og:url и абсолютные ссылки на обложку в `index.html`.
- Удалить только тестовые строки перед передачей клиенту.
