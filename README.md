# Эдгар и Кристина

Свадебное приглашение, 30 января 2027 года. HTML, CSS, браузерный JS и Vercel Function без внешних зависимостей.

## Google Таблица

1. Создайте или откройте таблицу для этого проекта. В настройках таблицы установите часовой пояс «Москва».
2. Откройте «Расширения → Apps Script», вставьте `apps-script/rsvp.gs`.
3. В настройках Apps Script → «Свойства скрипта» добавьте `RSVP_SECRET`: длинную случайную строку. Сохраните её для Vercel; не добавляйте секрет в GitHub или HTML.
4. Запустите `setup` из редактора и предоставьте разрешения. Скрипт запомнит ID таблицы и создаст лист «Ответы гостей» с заголовками. Повторный запуск не стирает ответы.
5. «Развернуть → Новое развертывание → Веб-приложение»: выполнять от вашего имени, доступ «Все». Скопируйте адрес, заканчивающийся на `/exec`.
6. После изменения кода обновляйте развертывание на новую версию.

Поля: дата ответа, имя и фамилия, присутствие, сопровождающие взрослые, будут дети. Шестая скрытая колонка хранит ID ответа для защиты от дублей при повторе запроса после ошибки сети. Отдельный новый ответ гостя создаёт новую строку.

## GitHub и Vercel

Публикуйте содержимое этой папки отдельным репозиторием. Макеты, исходная музыка и локальные настройки исключены. В Vercel импортируйте репозиторий, Framework Preset: Other, корень проекта — корень репозитория; без команды сборки и без отдельной папки вывода. Vercel обслуживает статические файлы и `/api/rsvp`.

В Environment Variables Vercel добавьте для Production и Preview:

- `GOOGLE_SCRIPT_URL` — адрес веб-приложения `/exec`;
- `RSVP_SECRET` — то же значение, что в свойствах Apps Script.

После изменения переменных создайте новый деплой. Ответы Preview тоже попадают в эту таблицу; тестовые ответы явно подписывайте «ТЕСТ».

## Проверка перед сдачей

`npm test` проверяет сервер и Apps Script с подменой сервисов: успешную запись, отказ, валидацию, ошибки Google, повтор без дублей и срок. Это не заменяет проверку реальной таблицы.

- На опубликованном сайте открыть конверт, проверить музыку и переключатель звука на телефоне.
- Отправить «ТЕСТ — присутствую» с сопровождающим и детьми; сверить строку в таблице.
- Отправить «ТЕСТ — не приду»; зависимые поля должны быть пустыми в таблице.
- Проверить узкий экран 320 px, обычный телефон и компьютер, отсутствие ошибок консоли и пропавших файлов.
- После получения окончательного адреса добавить абсолютные Open Graph URL и обложку для пересылки в мессенджерах.
- Удалить только тестовые строки перед передачей клиенту.
